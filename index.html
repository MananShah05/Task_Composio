4. The agent

Pass 1 · Draft
Web search + fetch official docs → structured JSON row: auth, access, API, MCP, verdict, evidence URLs.
Pass 2 · Verify
Separate adversarial agent re-opens each evidence URL and searches for contradicting docs. Marks fields ok / wrong / unverifiable.
Revise
Wrong fields returned to researcher with specific objections. One round of re-research per disputed field.
Human flag
Still-disputed or low-confidence rows get needs_human=true. 20-app stratified sample hand-checked for scoring.

Tools & security

  • Read-only tools only — web_search + fetch. No shell, no write, no send tools.
  • Prompt injection defence — fetched content labelled as UNTRUSTED DATA in every prompt; injection attempts flagged automatically.
  • Schema validation — every field coerced to allowlists; HTML stripped; key-shaped strings redacted; only https:// evidence URLs kept.
  • SSRF guard — model-chosen URLs rejected if non-https, private IP, localhost, or cloud-metadata host.
  • Composio MCP — optional; plugs in as a read-only toolkit via COMPOSIO_MCP_URL. Zero impact if not set.
  • Atomic writes — results saved with os.replace so a crash never leaves a half-written file.
  • Resumable — already-processed IDs are skipped on restart.

5. Proof

# 1. Install
pip install anthropic

# 2. Set secrets (never commit)
cp .env.example .env
# edit .env: add ANTHROPIC_API_KEY (and optionally COMPOSIO_API_KEY + COMPOSIO_MCP_URL)

# 3. Smoke test (5 apps)
python agent.py --limit 5 --out smoke.json

# 4. Full run (all 100, resumable)
python agent.py --out results.json

# 5. Dead-link check
python check_links.py results.json          # → link_check.json

# 6. Human sample
python sample_check.py make                 # → human_check.csv
# open docs by hand, fill *_human + human_evidence_url + root_cause
python sample_check.py score                # → verification.json

# 7. Build page
python build.py                             # → index.html

Repo contains: apps.csv, agent.py, sample_check.py, check_links.py, build.py, template.html, SECURITY.md, .env.example, .gitignore. Deploy index.html + results.json to any static host (Vercel, Netlify, GitHub Pages).
